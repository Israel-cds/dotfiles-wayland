# Dotfiles Wayland:

Contém arquivos de configuração dos seguintes softwares:

- Dwl (Window Manager)
- waybar (Barra de Status)
- wofi(App Launcher)
- foot (Terminal emulator)
- oh-my-posh (Terminal prompt)
- fastfetch (Infos do Sistema)
- swaybg (Background for wayland)
